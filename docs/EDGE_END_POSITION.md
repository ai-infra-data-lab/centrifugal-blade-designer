## 現行の定義

円・楕円・互換用Tangent arcは、完成したLEの最小子午面距離、TEの最大子午面距離を、
指定したLE/TE位置へ合わせる。RCは外径→内径でも流れ方向の距離が増えるので同じ定義。
任意の曲がった壁面の全体R最小/最大、Z最小/最大を意味しない。

平均線の端点、β・厚さ分布、Stacking/Rakeの基準、Splitter開始fractionは保持する。
両側の接点を元PS/SS上で内側へ動かし、接線条件と先端位置を同時に解く。
平均線を短縮したり、完成した円弧を非一様に変形したり、先端を平らに切って合わせたりしない。
これにより、同じJSONから生成する丸め端部・切詰め後のPS/SS座標は以前から変わる。
JSONの入力値・既定ファイル・ユーザー原本・歴史的数値fixtureは書き換えない。

中央2Dは選択3D断面の投影であるため、この形状へ追従する。
旧radial 2D API（診断用）は従来の生成法を維持する。

## 数値方法

`geometry/edge_positioning.py`で、PS接点uとSS接点vを未知数にする。
PSの内向き法線n、両接点差dから `R = (d·d)/(2 n·d)`、`C = P + R n`を求める。
SS側の接線条件と、円の子午面方向の極値が目標mに一致する条件を数値的に解く。
楕円は既存と同じ流れ方向のアフィン変換を使い、元座標へ戻した楕円の極値を拘束する。
端部幅で正規化した残差、正の半径、向き付き両接線、単一の非一周弧を確認する。

接点探索は各端から元側面パラメータの45%まで。従来の位置非拘束15%探索とは別の問題で、
有限厚さの先端を内側へ置くために接点がより内側へ移動することがある。
LE/TE接点区間の重複、側面が指定区間外へ出る場合、解が見つからない場合はエラー。
有限初期値の局所探索であり、すべての円/楕円の存在・一意性を保証しない。
小さい弦長や急な厚さ/β変化では従来成立した入力も不成立になり得る。
半円への退避、biarcへの切替、公差緩和で成立扱いにはしない。

円/楕円の距離極値は標本のmin/maxだけでなく、解析的な停留角から計算する。
masterと出力の点数は保ち、極値の点を端部配列の中央indexへ含める。
masterの円弧パラメータは左右の割線速度と調和平均を使う単調なCubic Hermite写像で連続化する。
先端を中央へ置くための単純な区分直線写像は速度が不連続になり、CAD近似を悪化させるため使わない。
TurboGridの既存中央indexマーカー規約と指定先端が一致し、粗い出力でも先端を落とさない。
有限厚さの丸め端部は両接点と先端のため出力3点以上を必要とし、2点はエラー。
直線Cutoffの2点出力は維持する。内部masterの最小分解能は既存どおり。
表示→master対応診断は従来の等距離標本と先端を保持する標本を厳密照合し、古い表示を拒否する。

元の法線オフセット側面のうち、最終的に切り捨てる構築部分だけは壁面端の接線で外挿する。
外挿は翼区間長の45%以内に制限し、公開する全曲線は有限壁面内で再検査する。
一定径Cutoffの側面は、距離の3次スプラインがTE直前に径を越える現象を避けるため、
距離成分をPCHIP、θ成分を既存の3次補間で評価する。径のガードは緩めない。

## 維持する例外と精度範囲

- Cutoffは従来の切断基準。特にImpeller TEはHub TE径の共通円筒で、Shroud TEの独立R/Zへは変更しない。
- Tip Clearanceは既存の翼Tip壁面への写像を維持する。ケーシングの指定R/Zに翼Tipを重ねて隙間を消さない。
- 派生Shroud/外径カットは元形状を生成してから実施する。切削後の端部が元LE/TE指定へ戻るわけではない。
- 端部厚さ0は縮退点。有限R/G1保証は従来どおり対象外。
- 真円/楕円は局所(m,y)座標内。曲面へ写像したXYZの真円性、全Span面のG1/G2、全面干渉は保証しない。
- CSV/TXT/ASCIIの丸め精度やCADの近似誤差は別の誤差。内部の目標一致を出力精度以上の保証と混同しない。
- 旧形状で出力した座標Study/準備済みjobは形状版の不一致として拒否する。既存fileを移行/上書きせず、新しいStudyから座標を出力して外部評価をやり直す。旧解析値を新しい端部へ流用しない。
