# 座標最適化：基準設計の移行と外部評価

2026-10-24：LE/TE先端の位置拘束へ形状生成を変更したため、Studyと準備jobに形状版`rounded-nose-1`を記録する。旧版/版なしの再開や出力は拒否し、旧外部結果を新端部へ誤適用しない。旧fileは保持し、新規Studyの出力・外部再評価が必要。[端部位置の定義・検証](EDGE_END_POSITION.md)。

## 対象と入口

`Tools → Coordinate Optimization / 座標最適化`を開く。
従来の別ウィンドウ最適化（legacy radial 2D）は変更せず、新しい作業画面を追加する。
対象は明示的な翼列IDを持つプロジェクト。Impeller・Diffuser・RCを同時に選択できる。
翼列一覧のない旧API snapshotはこの画面で扱わず、既存Editor/legacy機能を維持する。

最適化の対象は数値パラメータと翼断面/壁面座標。座標を作るために既存のβ積分、
Hub/Tip・既存Spanの断面生成、Rake・Splitter・クリアランス・派生カットの数値処理を使う。
Span面の最適化、面全体の干渉/誤差判定、全周CAD組立て、fillet、mesh、CFDは実行しない。
CSVのengine識別名meridional_3dは既存座標形式との互換性のため維持する。
Studyの翼列CSV/TXTは15有効桁を使用し、通常Editorの出力桁数設定は変更しない。
各翼列のmetadataは同じ候補snapshot hashを使い、variantはcoordinate_studyとして識別する。

## 操作

1. 通常Editorの値を確定し、この画面で「現在の設計を移行」を押す。通常設計へはまだ適用しない。
2. 対象翼列を選択。変数の使用・上下限・必要なら連動グループを設定する。
   対象翼列を変更すると変数設定/現在結果を作り直すため、先に翼列を選ぶ。
3. 座標出力設定でXYZ/円筒列・列順・Span分割・Hub/Shroud・図面用/解析用Shroud・CSV/TXTを選ぶ。
4. 外部解析条件IDを必要に応じて入力する。同一回転数/入口条件/作動点等を外部で管理し、
   その条件を識別する文字列を使う。未指定なら解析条件の同一性は検査できない。
5. 候補数とseedを指定して「基準＋候補を出力」。必ず新しいフォルダ名を使う。
6. 外部解析を実行し、external_results_template.csvのコピーへ結果を記入して取り込む。
7. 目的列・最大化/最小化・任意の評価列の上下限制約を指定して順位更新。
8. 候補を選び、通常設計へ適用するか、選択候補の近傍LHSを新しいStudyへ出力する。

LHSは候補の実験計画、Local LHSは選択候補の周りの局所実験計画であり、
代理モデル最適化・自動CFD実行・大域最適解保証ではない。外部評価を見て反復する初期基盤。

## 第2段階：外部評価からのRBF次候補提案

`外部結果から次候補を出力 / RBF`を追加した。単一目的の最大化/最小化と現在の外部評価制約を使い、
予測する有望点と未探索側の候補を新しいStudyへ出力する。外部CFD・CAD・meshは実行しない。
通常Editorの設計値・JSON・β積分/厚さ/子午面生成・既存LHS/Local LHSは変更しない。

1. 少数の変数を選び、必要ならHub/Tipや翼列間を連動する。画面に独立変数数と必要成功評価数を表示する。
   d次元で`max(8, 2d+4)`点以上の、目的値/制約値がそろった成功評価が必要。
   基準も成功評価すれば1点。これは保守的な実装条件であり、予測精度の理論保証ではない。
2. 十分な候補数でLHSを出力し、空でない外部解析条件IDを設定する。
   条件IDは回転数・入口/出口条件・作動点・mesh/solver設定・評価量の定義/単位など、比較条件を識別する。
3. 外部解析結果CSVを取り込み、目的列・最大化/最小化・任意の制約を指定する。
4. RBFボタンを押し、1〜50候補と新しい保存先を指定する。学習/検証/座標生成は所有processで実行する。
5. 新Studyの予測列と診断を見る。外部評価列は未評価のまま。結果CSVテンプレートもpendingであり、
   予測をefficiency等の実評価欄へ自動コピーしない。新しい候補を外部で評価して再び取り込む。
6. さらにRBF提案すると、同じ基準/有効変数・範囲・連動/翼列/形状版/解析条件の過去実評価を引き継ぐ。
   run ID付きの履歴で混同を防ぎ、少なくとも1つ新しい候補の成功評価が必要。

### 方法と条件

- 連動群は1軸、各軸は共通上下限で0〜1へ正規化する。基準0が探索範囲外でも、その実評価は保持できる。
- SciPy `RBFInterpolator`のthin-plate spline、一次多項式、固定smoothing=1e-6を使う。
  各評価量をアフィン正規化して学習する。独立変数を張らない/悪条件のデータ、重複/極近接観測は拒否する。
  評価量を最大絶対値で正規化してから変動を検査し、単位の正の倍率変更で有望点の選択が変わらないようにする。
- seed付き4分割で保持データを予測し、訓練平均を返すモデルよりRMSEが小さい場合だけ採用する。
  目的値に分解可能な変動がない場合も拒否する。定数の観測制約は定数予測とし、全域一定とは認定しない。
- 2048点の有界LHSプールから予測制約内の候補を選ぶ。先頭`n-floor(n/4)`件は予測目的値順、
  残りは既試行/今回選択点からの正規化RMS距離が大きい点。既試行との距離1e-5以下、
  同一バッチ内の距離0.02以下は再選択しない。足りなければ制約や距離を緩めず失敗する。
- 学習上限250点、履歴の試行ベクトル上限2000。過去の座標生成失敗/解析失敗/未評価のベクトルも再提案しない。
  出力済みStudyを破棄せず、必要なら元Studyから別seedで別バッチを作れる。
- 過去と同じベクトルの新しい成功評価は古い評価を置き換え、置換元/先IDを記録する。無断平均はしない。
  明示的な新しい解析失敗は古い成功評価を無効化する。未評価を新しい実評価として追加しない。
  同一入力CSV内の成功した重複ベクトルは、利用する評価を明示してもらうため拒否する。
- 履歴には得られた数値評価列を保持するが、今回の目的/制約が欠ける行は学習しない。
  有効な変数/範囲/連動や解析条件を変更した場合は混ぜず、新しい評価Studyから開始する。

方式の一次資料：[SciPy RBFInterpolator公式資料](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.RBFInterpolator.html)。
同資料の多項式rank条件、異なる観測点、点数増加時のメモリ特性を踏まえて制限する。
上記の点数条件・検証/距離/選択ルールは本アプリの実装方針であり、SciPyの精度保証ではない。

### 出所・出力保護

CSV取込前後は1 MiBずつ分割してhash照合し、大きな既存CSVも照合のために丸ごとメモリへ載せない。
取込時のCSV hashを固定し、提案準備時に同じCSVであることを照合して私有jobへ凍結する（最大4 MiB）。
学習processは元Studyの基準/候補hash・全出力hashとcanonical manifest hashを再検証する。
取込後のCSV変更、異なる解析条件、旧形状版、異なる有効変数、改変した座標/履歴は拒否する。
凍結後に元CSVを編集しても開始済みjobのデータは変わらない。

新manifestの`sampling=rbf_external`、`proposal`へ出所run/hash、使用実評価、置換/無効化、
モデル条件、seed、学習数/独立次元、4分割検証RMSEと平均モデルRMSEを記録する。
各提案の`prediction`は`PREDICTED_NOT_EVALUATED`。baselineには予測を付けない。
再開時は予測metadataも検証し、NaN・偽の検証済みstatus等を拒否する。manifest上限16 MiBも公開前に検査する。
全候補は既存の座標生成・成立検査を実行し、不成立ならFAILEDとして座標を残さない。
既存出力先を上書きせず、取消/close時は既存の所有tree停止と公開保護を使う。

予測分散/確率的な不確かさは未推定。予測制約適合・4分割検証成功は、実CFDでの適合や改善の保証ではない。
多目的/Pareto、Gaussian Process/Bayesian探索、自動solver起動、3D面/CAD制約の追加は未対応。

## 基準を保持する変数

通常のPCHIP制御点とその数を保持する。補正0では元設計をdeepcopyし、
再サンプリングやarc半径の再計算も行わない。少数パラメータ化のために元分布を近似し直さない。

- β：各既存制御点sへ `(1-s)ΔβLE + sΔβTE + 4s(1-s)Δβbow`を加える。
  bowは端点を変えない補正で、中央角度の絶対指定ではない。元の点位置から同じPCHIPで生成する。
- 厚さ：内部点の倍率[%]、最大制御点位置の移動、LE/TE厚さの独立差分[mm]。
  内部倍率は端点厚さを変えない。位置移動は単調な区分線形座標変換を使う。
  最大点が端点にある分布や端点を越える移動は拒否する。平坦最大は最初の最大点を使う。
- Impellerは既存各Spanを個別に扱い、Diffuser/RCは現在の共有分布を維持する。
  スプリッターは既存専用分布だけを個別変更できる。主翼連動を自動的に専用分布へ切り替えない。
  開始位置/周方向位置も差分指定可能。専用分布の補正は実際のLE〜TEだけに適用する。
- 翼枚数・端部形式・Rake・クリアランス・派生カット・CAD寸法/fillet Rは既存値を保持する。
  これらの専用探索変数や整数/形式変更の探索は今回未実装。

同じ補正名の変数へ同一の連動グループ名を与えると一つのLHS次元から同じ差分を与える。
例えば複数翼列/Hub/TipのΔbeta_teを連動できる。共通の上下限は各範囲の共通部分。
異なる意味/単位の補正や、共通範囲のない連動は拒否する。

## 共有子午面

子午面はプロジェクトに一組。直線/円弧の数・順序・方向・所属翼列を固定する。
始点R/Z・始点接線角の差分、各segmentの長さ倍率、円弧の曲がり角差分を登録する。
円弧の半径は弧長/曲がり角[rad]で決める。前のsegmentの終点/接線から続ける既存G1生成を使う。
長さ0以下・曲がり角0以下・不成立な座標は拒否し、直線への自動変換や修復は行わない。

所属がある壁では、各翼列の所属区間に対するLE/TE相対位置を保持して新しい全壁fractionへ変換する。
影響する非選択翼列も含めて座標生成を確認する。所属が欠落/不連続、基準LE/TEが所属区間外なら、
その壁変更候補を失敗として残す。所属がない旧壁は既存の全壁fractionを維持する。
R/Zは候補の壁面から求まる結果。R/Z固定、出口位置/接線角の等式拘束、中心線＋幅の表現、
segment追加削除/再割当ての探索は今回未実装。元の子午面・所属・設計値を自動修正しない。

## 出力と外部結果

- baseline.json：元の全設計snapshot。既存のユーザーJSONを上書きしない。
- manifest.json：run ID、基準hash、対象翼列ID/名前/種類/ディレクトリ、変数/連動/範囲、seed、
  出力列/単位/軸、解析条件ID、全候補の差分・snapshot hash・生成状態・出力file SHA256。
  各翼列のMain/Splitter・既存Span・LE/PS/TE/SS順と点数、壁面chunk点数も記録する。
- case_0000：中立の基準。以降はcase_0001…の候補。row_001…は名前でなく全プロジェクト内の順序で固定。
- 各候補のshared_hub_rz.csv/shared_shroud_rz.csv：共有元壁面のZ/R座標。
  各翼列の壁面出力は既存Exporterと同じ所属範囲・実Tip/派生/指定Shroud処理を使い、共有元壁と混同しない。
- external_results_template.csv：run_id/candidate_id/candidate_hash/evaluation_context/statusと評価列。
  statusはpending/success/failed。評価列はefficiency等の任意の数値列へ変更/追加できる。

外部結果は同じrun ID・候補hash・設定した解析条件IDを照合し、重複候補/重複列、
未知候補、非有限値、座標失敗候補を拒否する。failed/pendingは評価値を空欄にし、0へ置換しない。
目的値/制約値が未取得の候補は順位へ入れない。GUIは一つの制約列、純粋APIは複数制約を扱える。
CSVに返された値が正しいCFD結果か、外部側の単位/境界条件が妥当かはアプリ単独では検証しない。

保存済みStudyはbaseline/candidate hash・出力file hashを検査して再開できる。外部結果は元CSVを再取込する。
再開時/取込時のfile検証は同期処理のため、大きいStudyや遅い共有ディスクではGUI待機が残り得る。
候補適用時は通常設計が基準snapshotから変わっていたら拒否し、適用は一つのUndo/Redo単位にする。

## 実行と保護

座標出力は標準.venvの所有子processで実行し、既存のprocess-tree取消/close待機を使う。
上限は20分、候補数は0〜1000＋基準1。進行中は設定を変更できない。
個別候補失敗時は座標fileを残さず理由を記録し、基準失敗時はStudy出力全体を中止する。
新しい出力先だけを使用し、既存caseの公開保護機構で一式を公開する。
取消が公開完了後だった場合は完成済みStudyが残り得る。旧出力を消して戻すことはしない。
