# 流路面積とスロート

対象は選択中のImpeller、Diffuser／RCの翼列です。表示と同じ3D master断面を読み取り、設計値・子午面所属・JSON・CSV・TurboGrid・CAD出力は変更しません。解析結果は保存JSONに追加せず、現在値から再計算します。

## 操作

1. 左の編集対象で翼列を選びます。
2. `View → Passage Area / Throat`を開きます。
3. `流路面積・スロートを計算 / Calculate`を押します。
4. 面積グラフ、スロート一覧、下側の「断面面積」「Span別スロート」を確認します。

計算は別スレッドで開始時点のコピーを使います。編集中・無効入力・子午面選択・翼列変更では結果を消し、遅れて完了した旧計算を採用しません。形状変更後は計算ボタンで更新してください。全周表示や出力点数によって測定形状を変えません。

## 流路面積の定義

長さはmm、面積はmm²、回転軸はZです。既存の`Flow Area`は全流路の総面積表示として維持します。新しい解析では、選択翼列の主翼がHubからTipまで存在する子午面直交断面だけを扱います。LE／TEが傾いている場合、全Spanが揃わない部分は対象外です。

平均子午線の法線と有限Hub／Shroudの正確なLine／Arc交点から総面積を求めます。

解析範囲は主翼LE／TEが全Spanで揃う区間です。TurboGrid出力用の所属区間の検証とは別に、共有子午面上の実形状を測定します。

`A_gross = π (R_h + R_s) L_hs`

翼枚数をN、主翼ピッチを`p = 2π/N`とし、各Spanのmaster輪郭を同じ子午面直交断面で切ります。交差する輪郭の周方向角区間を翼厚による閉塞とします。開口幅は`R × 開口角`で、Hub–Shroud間の物理距離に対して台形積分します。

曲線壁では「解析的な壁面→壁面ポリライン→master断面」の二段階サンプリング誤差があります。Hub／Tip端点は、その円弧の矢高から導いた誤差予算と交差角の範囲内でだけ、正確な壁面交点へ合わせます。実際にずれた断面を任意の許容値で合わせる処理ではありません。解析壁面・元のmaster形状は変更しません。

- **Gross / N**: 総面積を主翼枚数で割った面積。
- **Main–Main reference**: 主翼厚だけを差し引いた1主翼ピッチの面積。スプリッター付きではスプリッターを無視した参考値。
- **Net / main pitch**: 主翼と、その断面に存在するスプリッターの厚さを引いた幾何開口面積。
- **Main–Splitter / Splitter–Main**: 回転方向に沿う主翼→スプリッターと、スプリッター→次の主翼の各面積。スプリッターが全Spanに存在する断面でだけ表示。
- **Net annulus**: `N × Net / main pitch`。スプリッター両側を表示するときも主翼間参考値を加算しません。
- **Tip-gap / N**: オープンインペラの実Tipから固定ケーシングまでの1主翼ピッチの幾何開口。Grossはケーシングまで、翼厚閉塞は実Tipまでで積分します。Netはこの開口を含みます。Splitter両側が求まる断面では両側面積＋Tip-gap / N＝Net / main pitchです。ゼロ隙間では0。詳細は[TIP_CLEARANCE.md](TIP_CLEARANCE.md)。

主翼だけの上流域でもNetは求められます。スプリッターが一部Spanにしかない断面では、存在するSpanの閉塞を積分したNetは近似として表示しますが、両側の面積はN/Aです。曲線に欠落があればグラフも接続しません。

面積は幾何学的な開口です。境界層・剥離・流量係数を考慮した空力的な有効面積ではありません。表示する最小面積は既存`area_points`等に基づくサンプル最小値で、連続関数の最小化ではありません。

## スロートの定義と近似範囲

主翼間、主翼→スプリッター、スプリッター→次の主翼について、同じSpanのLE／PS／TE／SSを含む閉master輪郭間の最小幅を求めます。PS／SSの名称だけから対向面を決め打ちしません。両側は個別に測定し、主翼間はスプリッター付きで参考値と明記します。

子午面の母線が直線の場合、円筒・円錐の展開面でmasterポリライン間の最小距離を計算します。円筒のHub内部を横切る短い3D弦を幅として使いません。半径方向の平面は円錐展開の特殊例です。計算上のポリライン精度はmaster解像度に依存します。

**子午面の母線が曲線の場合は、3D直線距離による下限推定です。** 壁面に拘束した測地線の最小化は未実装で、直線が壁面内部に入る可能性も含め、厳密なスロートとは扱いません。画面の説明と各行のStatus／ツールチップに区別を表示します。

各Spanで得た最小幅を、両端点の子午面中点が作るHub–Tip方向の物理距離で台形積分し、近似スロート面積を表示します。全周換算は同じ種類の通路がN個あるものとしてN倍します。

これは既存断面に基づく**幾何近似**です。Span間にある未サンプルの最小幅、異なるSpan同士の干渉、曲面全体で最適化したスロート面、フィレット、翼端隙間の漏れ流れ、粘性やチョーク流量を評価しません。隙間指定時のSpan積分は実翼Hub–Tip高さです。静翼に中間Spanを新規生成しません。ねじれやLE／TEの傾斜が強い形状では断面数・解像度に対する収束確認が必要です。

展開距離の一意性を保証できない広角・多巻き配置は幅をN/Aとします。展開ポリライン間距離も、有限の流路入口・出口を迂回条件として解いた距離ではありません。少数翼などで最短線が有限流路の外へ出る場合、実際の流れのボトルネックとしては使用できません。

## 無効形状

接触・翼厚によるピッチ閉塞・スプリッターの主翼との重複・多価の断面交点・Spanの崩れ・対応しないSplitter Span・主翼枚数2未満等は、該当計算を利用不可として理由を表示します。検出したピッチ重複があるとスロートも成功扱いしません。全ての3D体積干渉を検出する機能ではありません。

利用不可の値を0へ置換せず、古い計算を現在値として残しません。解析経路にはファイル書込み処理を置かず、既存の正常な出力を保護します。
