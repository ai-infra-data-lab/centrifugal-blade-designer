# 翼Tipを固定した解析用Shroud

図面用のケーシングと翼Tipを正本として残し、解析用のケーシングだけを別の隙間で生成します。Impellerに適用し、MainとSplitterで同じ実Tip・ケーシングを使います。静翼へのクリアランス追加ではありません。

## 操作

1. Impellerを選び、`LE / TE → オープンインペラ / Tip Clearance`を開きます。
2. 上段のLE/TEは従来どおり図面用の隙間です。図面ケーシングから翼Tipを生成します。
3. `解析用Shroudを別作成（翼Tip固定）`を有効にします。初期値は現在表示中の図面用LE/TEです。
4. 解析用LE/TEの隙間をmmで入力し、Enterかフォーカス移動で確定します。解析値の変更では翼Tip・翼面・角度・厚さを変更しません。
5. 子午面の紫破線`Analysis Shroud`と、3Dの紫色の回転面を確認します。3Dの`Analysis`チェックで表示を切り替えます。橙は図面ケーシング、緑は実Tipです。

図面用0 mmの翼でも、親のTip Clearanceを有効にして解析用だけ正の隙間を指定できます。解析用0 mmでは解析ケーシングを実Tipの子午線に合わせます。解析用を無効にすると従来の図面形状・出力へ戻ります。設定は翼列ごとに保持し、Undo/RedoとJSON保存/読込へ対応します。

## 幾何学的な定義

基準は生成後の図面ケーシングに沿う距離sと、そのHub側へ向く単位法線n(s)です。実Tipの子午線をT(s)、解析隙間をg(s)とすると、解析用Shroudは次式です。

`S_analysis(s) = T(s) − g(s) n(s)`

g(s)は実Tipの保持されたLE/TE端点を図面ケーシングへ投影した距離の間で線形補間し、区間外では端の値を維持します。一定外径TE・外径カットにも保持された実端点を使います。R/Zとも必要に応じて変化し、半径だけ／Zだけの一律オフセットではありません。

この隙間は図面ケーシングの共通法線方向で定義します。解析用壁面自身の法線で測った最近接距離とは一般には一致しません。可変隙間・曲率を持つ場合も基準を変えず、翼形状の再生成による混同を避けます。新しい壁面は既存の実Tipサンプルに対応するポリラインです。投影で生じる数ULPの重複距離だけを除去し、幾何学の短区間・公差を緩和して失敗を隠しません。

解析Line/Arcでは元の解析的法線、派生カットのポリラインでは図面用Tipの生成に使う連続した節点法線を距離補間・正規化して使います。区間ごとに突然切り替わる折れ線法線でオフセットして微小な折返しを作ることを避けます。

派生Shroudカット後は派生した図面ケーシング・実Tipから作成します。元の解析Line/Arc、図面用Shroud、実翼断面は置換しません。所有区間は元の壁面への距離対応を保持するため、別翼列の区間まで混在させません。

## 出力と解析の使い分け

|処理|参照する形状|
|---|---|
|中央の翼・Mechanical STEP・通常CADプレビュー|図面用の実翼。解析隙間を変えても同じ|
|子午面・3D|図面Shroudと解析Shroudを重ねて区別|
|汎用CSV/TXTの翼|常に共通の実翼|
|汎用CSV/TXTのShroud|図面用／解析用／両方を明示選択|
|TurboGrid ASCII Profile Points|解析用が有効なら解析Shroud、未設定なら従来の図面Shroud|
|TurboGrid CAD|解析用Shroudは未対応。図面隙間0でもjob作成前に拒否|
|通常のFlow Area/Throat|従来の図面ケーシング・実Tip基準を維持|

CSV/TXTの解析壁面は`analysis_shroud`（θ=0）で識別します。両方を選ぶと、一括出力では識別列で区別し、壁面別出力では`shroud`と`analysis_shroud`の別ファイルになります。識別列を外すと単一ファイル内で両者を区別できないため、必要に応じて壁面別出力を選びます。

TurboGrid ASCIIでは実Tip断面を保持し、正の解析隙間があるときは解析Shroudまでの延長断面を追加します。読込み時は従来と同じく実TipのProfile Numberを指定します。解析隙間が両端0なら追加延長は不要です。Main/Splitterとも同じ解析ケーシングへ接続します。壁面の所属範囲と丸め後の輪郭を確認してから保存し、無効時は既存ケースを保護します。派生カットのTurboGrid出力は従来どおり未対応です。

解析用Shroudの計算は形状の作成であり、アプリ内のFlow Area/Throatを別の解析条件へ自動で切り替えるものではありません。製作形状の指標を従来と同じ基準で確認できます。

## 保存と検査

`tip_clearance`の既存`le_mm`・`te_mm`を保持し、任意の`analysis_le_mm`・`analysis_te_mm`を追加します。未設定時は両方Noneで、保存JSONへ追加しません。従来の2項目だけのJSONも読込み可能です。片側だけの指定、負値、非数・無限値は拒否します。

解析壁面の正半径・有限性・順序、自己交差、Hubとの交差を検査します。保存・出力は現在値から再計算し、エラー時に前回の表示形状を誤って保存しません。サンプル子午線の検査は、3D翼面全域の非接触やANSYSのメッシュ成立を認証するものではありません。

変更箇所は、設定と保存（models/parameters・validation・fileio/project_io）、数値処理（geometry/analysis_shroud・geometry_3d・row_domain）、表示（tip_clearance_editor・context_meridional・preview_3d・main_window）、座標出力（coordinate_csv・coordinate_export_dialog・turbogrid_export）、CAD保護（cad/client）です。Qtやファイル形式へ依存する数値計算は追加していません。
