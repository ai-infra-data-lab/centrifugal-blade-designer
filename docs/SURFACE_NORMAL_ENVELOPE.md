# 同一対応スプラインの法線角区間包絡

Stage 3Aの位置差・Jacobian包絡に続き、`geometry/surface_orientation.py::surface_normal_envelope`を追加した。既存の形状生成、GUI、CAD格子選択、保存・出力ガード、公差は変更しない。Qt/OCP/ファイル形式から独立した読取り専用の数値診断であり、Hypothesis/uvは追加しない。

## 対象と対応契約

両面はclamped/非周期、同degree（各方向1〜3）、領域[0,1]²の実XYZ tensor splineとする。元knot多重度でC1を保証できない面は拒否し、継ぎ目の法線を平均化しない。形式上C0でも偶然に滑らかな面は、この保守的な構造検査の対象外となる場合がある。

同じSpan・同じrole内xiが比較したい物理位置へ対応することは呼出し側の責任である。異なるroleや逆向き座標を自動照合しない。今回の法線は`N = dS/dspan × dS/dxi`の向きであり、CAD solidの外向きではない。内積の絶対値を取らず、逆向きは180度として扱う。原点・単位・回転軸の変換、最終cap/fillet/STEP、通常Previewの物理対応は本APIの対象外。

## 包絡の導出

1. 両面のknotの和集合と指定回数の中点で共通Bézier区間を作る。refit/degree昇格や元係数の変更は行わない。
2. 区間のcontrol差分を元のSpan/xi区間幅で割り、微分の外積のBernstein係数を求める。各Nのノルム下限は前段のJacobian包絡と同じ手法で計算する。XYZがmm、座標が無次元なので下限の単位はmm²の面積密度。
3. 各Nをそれぞれの係数ノルム最大値で正規化する。この正の定数倍は角度を変えない。内積・外積の積をBernstein基底の積の係数へ畳み込む。同indexのpoleどうしの積ではない。
4. 正規化後の内積係数の最小値をL、外積係数ノルムの最大値をUとする。L>0なら全区間で角度は90度未満で、上限を`atan2(U,L)`とする。L>0を確保できない正則区間は保守的に180度とする。

Bernstein基底は非負・和が1なので、係数の凸包が区間内の値を含む。内積が正の場合に限り`tan(angle) <= U/L`を利用する。どちらかのJacobian下限が閾値以下、または未定義法線の標本がある場合は角度上限を**None**にする。退化があるとの断定でも、角度0/PASSでもない。

基底積の恒等式とknot挿入は[前段の導出](SURFACE_REGULARITY_ENVELOPE.md)を参照。この実数モデルの性質とfloat64実装を区別する。丸めの区間保証はなく、`roundoff_certified=False`を必ず返す。結果を製造公差の保証や出力許可へ接続しない。

## APIと結果

```python
result = surface_normal_envelope(first, second, singular_mm2=1e-12,
                                 refinements=0, max_cells=4096)
```

閾値はcallerが有限・非負で明示する。上例は測定用で、CAD/設計の受入れ公差ではない。細分化は0〜4回、共通cell数上限を超えるとBézier net作成前に拒否する。非有限入力/演算はValueErrorにし、代替面・法線を作らない。

各cellには範囲、両面のJ数値下限、角度上限、元スプラインの3×3標本での最大角度、未定義の標本ペア数を返す。標本角度はatan2で計算し、数値上の矛盾で包絡が標本最大より小さくなる場合は標本最大まで引き上げる。全体の`angle_upper_degrees`は1cellでも未判定ならNone。`unresolved_cells`と`sample_undefined_pairs`を必ず併記する。標本最大は有効なペアだけの値で、全部未定義ならNone。共有境界の標本は重複計上され、一意の物理点数ではない。

180度の包絡は「どの方向もあり得る」であり、反転を観測した証拠ではない。反転の観測には90度を超える実標本等の別根拠が必要。正のJ・法線の近さから自己交差や隣接翼/Splitterの干渉なしを推定しない。

## 独立解析試験と実CAD照合

- 平面の0/25/60/90/120/180度。正負を区別し、小角では解析角の包絡が一致する。
- 正の座標スケール0.01/1/100、異なるknot、入力の係数/knot不変、比較順の入替え、3次解析面の密な独立角度式。
- `S0=(t,s,0)`、`S1=(t,(s−0.37)³/3−0.005s,0.01s)`。S1のJは常に正で、内積の符号は`(s−0.37)²−0.005`に従う。0/0.5/1の標本はすべて90度未満だが、s=0.37で約116.565度になる。無細分の包絡は180度を残し、小さい標本最大を全面上限にしない。4回細分すると90度超の標本を得る。
- 非標本位置s=0.37で潰れる折返し面、全面退化、不正な閾値・細分・リソース制限、C0と異degreeを拒否する。
- 独立OCCT processでMain/Splitter×LE/PS/TE/SSの33/65基準面を作り、共通全cellの3×3点でD1の外積から角度を測定する。有限の上限がある区間の包含と、すべての区間の標本最大を比較する。J下限が確保できない区間は明示して全体上限をNoneに保つ。比較許容は4096×機械epsilon×180度であり、CAD公差を変更しない。

実装途中の25純数値試験で1件の解析式の微分方向を誤記し、外積を独立に導出し直して修正した。その後の実CAD試験で「全区間が解決する」という試験側の仮定が1件失敗した。LEに未判定区間がある事実を保持し、境界を外したり閾値を緩めず、未判定の意味も検証する契約へ修正した。既存fixture/期待値は変更していない。修正後の関連80件は成功（`20261018T074425Z-da8b8713`）。
