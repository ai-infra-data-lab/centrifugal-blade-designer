# スプリッターのLE–TE専用編集範囲

現在の角度・厚さの編集場所は主翼と共通のBlade Angle／Thicknessタブです。Splitterタブには開始位置・コピー等を残しています。[共有グラフの操作](SHARED_GRAPHS.md)を参照してください。以下のLE〜TE限定と補間互換の仕様は維持します。

## 操作

Impellerの`Splitter`で有効にし、`主翼からコピーして角度・厚さを独立編集`を選択します。横軸は従来の**主翼LE=0、主翼TE=1**を維持します。スプリッターのLEを新たな0へ正規化しません。

各SpanのBlade Angle／Thicknessの表・ドラッグ点は、スプリッターLEからTE=1の間だけを表示します。例えばHub開始35%、Tip開始65%なら、Hubは0.35〜1、Tipは0.65〜1、Span 0.5は0.50〜1です。開始位置より上流の点は表にもドラッグ対象にも表示しません。

- LE点の横位置はHub／Tip開始位置から決まり、その場で値を編集できます。TEは1に固定します。
- 中間点はLE–TEの中で移動・追加・削除できます。端点は削除せず、点の順序を維持します。
- Hub／Tip開始位置を変更すると、保存済みの全Spanについて`f(span)=(1-span)×fHub+span×fTip`で表示範囲が追従します。横軸0–1の意味は変えません。
- 厚さは従来どおり倍率適用前です。主翼連動、再コピー、連動へ戻す操作を維持します。数値入力はEnter／フォーカス移動で確定します。

## 現在の補間と旧データ（2026-10-17改定）

専用スプリッターは、表示中のLE〜TEの点だけで、主翼と同じPCHIP補間を行います。2点だけなら直線です。以前の方式では非表示の上流点も傾きに影響しましたが、この影響を除きました。上流点の保存データとJSON形式は保持します。**コピー直後・既存の専用スプリッターを読み込んだ直後も、新しい補間で形状が変わる場合があります。** 主翼連動モードは主翼の分布をそのまま切り出す従来どおりです。

LEに元から制御点がなければ、保存済みの元曲線からLE値の初期値だけを取ります。未編集の表示境界は保存データへ追加しません。LE・TE・中間点の編集、点の追加・削除があった時点で、表示中のLEを実制御点として固定します。下流点を編集してもLE値は動きません。範囲更新だけでは保存データを変えません。開始位置を変更したときの翼長・物理LE位置の再計算は従来どおりです。詳細は[SPLITTER_INTERPOLATION.md](SPLITTER_INTERPOLATION.md)。

開始位置を上流へ戻せば、保持していた点が新しいLE–TE範囲内に入るため再び表示されます。開始位置の変更で専用分布を勝手に消去しません。独立編集後の主翼β・厚さへの非追従、TE位置・Rake・端部・クリアランスの継承は従来どおりです。無効な元データでは境界値を作らず、元データと検証メッセージを維持します。
