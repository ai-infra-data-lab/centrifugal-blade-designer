# 主翼・スプリッターの共有グラフと表示範囲

## 操作

Impellerの`Blade Angle`／`Thickness`で、主翼とスプリッターを同じグラフに比較表示します。グラフ下の`主翼 / Main`・`スプリッター / Splitter`で編集対象を選び、選んだ対象の点をドラッグするか、表で入力します。両方の線は表示したまま、選択した対象の操作点だけを表示して誤操作を防ぎます。

- 主翼は従来のHub青／Tip橙、スプリッターはHub緑／Tip紫の一点鎖線です。主翼の操作点は円、スプリッターは三角です。凡例には対象とSpan名を表示します。
- スプリッターが主翼連動の場合も実際の分布を比較表示します。専用編集側の`主翼からコピーしてスプリッターを編集`で独立編集へ移れます。専用分布は表示中のLE〜TEの点だけでPCHIP補間するため、コピー直後でも形状が変わる場合があります。現在の仕様は[専用分布の補間](SPLITTER_INTERPOLATION.md)。
- `Splitter`タブには開始位置・周方向位置・厚さ倍率・連動／コピーを残し、`角度を編集`／`厚さを編集`から共有グラフの専用編集へ移れます。別の角度／厚さグラフを同時に維持しません。
- 横軸は主翼LE=0・TE=1のままです。スプリッターの操作点は各SpanのLE〜TEだけとします。上流点は旧JSONとの互換性のため保持しますが、専用分布の点間の傾きには使いません。厚さは従来どおりスプリッター倍率適用前のパラメータ値です。
- 主翼と専用スプリッターの制御点は独立しています。Undo／Redo、翼列切替、静翼切替、New、JSON読込・保存へ接続し、計算・既定値・JSON／CSV／TurboGrid／CAD形式は変更しません。

## 全体表示

2Dグラフは、タブや解析ウィンドウを表示した後、Qtのレイアウトが確定するイベントで、有限な表示データ全体に余白を付けて範囲を合わせます。翼列・Span・投影面など表示対象の切替でも、表示中の関連2Dグラフを合わせます。MetricsのPitch／Solidityや曲率／曲率半径の表示切替にも対応します。

入力中や点のドラッグによる形状更新だけでは範囲を合わせ直さず、手動ズームを保ちます。グラフを再び開いた場合は全体表示へ戻ります。共有グラフ右上の`全体表示 / Fit`、既存の`View → Fit View`からも手動で合わせられます。

3Dも初回表示・ウィンドウ再表示後に、方向を保ってモデル全体が収まる倍率へ合わせます。通常の編集・ドラッグ・常時表示中のカメラ保持は維持します。数値的に全曲線が範囲に入ることと、実ディスプレイ／DPIでの操作確認は区別します。

## 変更箇所

- `gui/combined_profile_editor.py`: 共有グラフ、編集対象タブ、連動時の比較線、色・線種・操作点、Fit入口。
- `gui/profile_distribution_editor.py`: 本来の制御点・グラフを共有し、再構築時に他方の凡例を消さない処理。
- `gui/splitter_editor.py`、`main_window.py`: 設定タブから共有編集への移動、同じ実3D分布の表示、対象切替時の範囲更新。
- `gui/plot_fitting.py`: Qt Showイベント後の遅延Fit。タイマーをグラフに所有させ、削除済みグラフのコールバックを残しません。
- `gui/plot_widgets.py`、`control_point_editor.py`、`metrics_widget.py`: 各グラフの表示時Fitと表示内容切替、操作点の形状。
- `gui/preview_3d.py`: Show後の方向を保持する全体表示。
- `tests/test_combined_distribution_gui.py`、`test_plot_presentation_gui.py`: 独立編集、同一グラフ実体、連動／専用／静翼の反復切替と不要グラフの除去、Undo／JSON、各グラフの初回・再表示・有限データ包含、編集時ズーム保持、3Dの画面内包含。
- `tests/test_preview_3d.py`: 画面を開く時のFitと、開いた後の編集でのカメラ保持を分けて検査します。空の操作点配列でドラッグを開始した場合も例外なく無視します。
- README／FEATURES／ARCHITECTURE／SPLITTER_EDIT_RANGE／本書: 操作・確認範囲。
