# Impeller派生設計：シュラウドカット・外径カット

状態：推奨案の面積削減率[%]、ケーシングと翼Tipの変更・絶対クリアランス維持を採用しました。設計・表示・解析・JSON／Undoを実装し、自動試験で検証します。派生形状のTurboGrid／CAD出力、実画面、性能は未検証／未対応の範囲を下記に明示します。

## 操作

1. 左のImpeller翼列を選び、`LE / TE`の`派生設計 / Shroud・外径カット`を有効にする。
2. `基準Gross面積の削減率 [%]`を指定する。10%なら元の各基準断面の90%を残す。mm²の絶対削減量の入力は今回は採用しない。
3. 外径は`外径カットなし`、`指定外径 [mm]`、`元外径からの切削率 [%]`から選ぶ。10%切削なら元Hub TE径の90%。元径と派生径・基準面積比を欄の下に表示する。
4. 数値はEnter／入力欄からのフォーカス移動で確定する。中央の2D／3D・Full Annulus・Flow Area・Passageは派生結果。角度・厚さグラフ、子午面のLine/Arc・LE/TE編集は元設計を維持する。
5. 設定は翼列ごとに独立し、Undo／Redo・JSON保存／読込に対応する。無効／0%では元設計を使用する。元のJSON原本や既定値ファイルは上書きしない。

## 一般的な方法と今回の採用方針

Xu／Amano（2012）は、Hubと元の翼角定義を維持し、翼高さまたはShroud輪郭を変えるflow cutを説明しています。局所翼高さの割合によるShroud cutと外径cutを区別し、外径cutが効率・運転範囲にも影響すると報告しています。[Empirical Design Considerations for Industrial Centrifugal Compressors, §7](https://onlinelibrary.wiley.com/doi/10.1155/2012/184061)

Dickmann（ABB、ETC2013）は、基準翼の入力データを変えず、新しいShroudで主翼・Splitterを切り出し、絶対Tipクリアランスを維持する例を示しています。流路面積の縮小による低流量化と、圧力比・効率を維持するためのShroud最適化を扱います。[Shroud Contour Optimization for a Turbocharger Centrifugal Compressor Trim Family](https://www.euroturbo.eu/paper/ETC2013-015.pdf)

今回の「全断面で一定の面積削減」は、局所翼高さを一律に縮める方法とは区別します。元の子午面の基準断面を固定し、その面積に対してカットする方式を提案します。以下の具体的な面積式・UI・処理順は、本アプリへの適用案であり、文献で標準化された唯一の方法とは主張しません。

## 保持する元設計

- Hub、元のLine／Arc、LE／TE設定、主翼・専用Splitterの角度／厚さ制御点を上書きしない。
- 元設計から通常の3Dを生成し、TE Rake・Splitterを適用してから派生形状を作る。
- Shroudに合わせてSpan全体を縮め直したり、カット後のTEを1へ再正規化して元のβ・厚さ分布を引き伸ばしたりしない。
- 切削後の翼面は元の翼面の残存部分から作る。元の流れ方向位置・Span位置との対応を保持する。
- カット無効／0%は元設計そのもの。繰り返し再計算してもカットを累積適用しない。

## シュラウドカットの面積定義

基準は元設計の平均子午線に直交する断面とし、既存のGross面積の定義を使います。翼厚を差し引いたNet面積は結果として別途表示し、入力のカット率と混同しません。元の断面平面を固定して比較するため、変更後の平均線から再定義した断面とは区別して表示します。

元のHub点HとShroud点Sの距離をb、R差をΔRとします。新しいShroud候補をH+t(S−H)とすると、既存の回転断面の面積式から

`A(t) = π × b × t × (2R_H + tΔR)`

です。採用した面積削減率cでは`A_target=(1−c)A(1)`とし、`0<t≤1`で解きます。正半径区間で単調に増えるため、安定した正の二次式の根を使用します。

軸流直線の解析チェックは`R_new²−R_H²=(1−c)(R_S²−R_H²)`、純径流の等半径断面では`b_new=(1−c)b`です。例えば軸流でR_H=50、R_S=70 mmを10%面積カットしたとき、単純な翼高さ10%カットのR=68 mmとは一致しません。

まずカット後のケーシングを作り、その内側に既存LE／TE隙間の法線距離を確保したTip境界を作り、元の翼面を切り出します。隙間は新ケーシングの対応LE–TE間の距離で線形補間します。既存Cutoffによって実TE位置が子午面の基準TE位置と異なる場合は、既存Tipの実TE基準を維持します。外径も併用した場合は、この隙間分布を含む翼面を後から径で切るため、新TEは途中の隙間値になります。

## 外径カットの定義

- 基準径は元ImpellerのHub TE直径`D_base=2R_Hub,TE`。
- 指定径[mm]または基準径に対する切削率[%]を選択。例：切削率10%は`D_new=0.90D_base`。残存径90%と切削率10%をUIで混同させない。
- `R=D_new/2`の円筒で元のPS／SSを切断し、新しいTEを円筒上で閉じる。元のTEを内側へ動かして翼全体を再生成しない。
- 角度／厚さの元データはそのまま。カット位置で参照する元座標も保持する。丸めTEをそのまま再配置するのではなく、加工後の端部はCutoffとして扱う。
- 主翼・Splitterへ同じ径を適用する。LEを切ってしまう径、交点なし、多重・逆行する切断、消えるSplitter等は明示的に拒否する。
- 両カットを使う場合は、同じ元設計に対してShroud cutを適用した後に外径cut。基準径や元断面は元設計から取り、再計算順で基準が変わらないようにする。

## 性能の扱い

面積比・外径比・残存Span／元の流れ方向範囲を幾何的な結果として表示します。面積削減率をそのまま流量削減率と断定しません。外径比の二乗を、そのまま圧力比へ適用しません。効率・すべり・サージ・ディフューザとの整合が変わるため、達成流量／圧力比の確定にはCFDまたは実験が必要です。

## 離散形状・制限

派生ケーシングは元平均線の1001基準点と元壁面の区間位置を含むポリラインです。各基準点では面積式を満たしますが、点間は離散補間なので任意の断面で厳密な解析曲線とはなりません。軸流／径流は解析解と比較し、曲線壁の別の37断面は面積比の絶対誤差2×10⁻⁵以内を試験します。この許容差は試験モデルの確認値で、任意形状の保証ではありません。

元のmaster曲線の対応点をSpan間で円筒座標線形補間した離散翼面を使います。派生断面を再サンプリングし、元Span・元流れ方向位置を保持します。元角度の再積分や厚さの再生成で短い翼へ全分布を引き伸ばす処理は行いません。元の中間Spanやmaster点数が少ない設計では、その離散面の近似精度にも依存します。連続CAD面の厳密なトリム・面全体の干渉／応力は今回の確認範囲外です。

Shroud cutは選択Impellerの私有の派生壁面に適用し、共有の元子午面や他翼列は変更しません。子午面編集では元壁面に派生Tip・casingを重ね、全翼列3Dは元壁面と各派生casingを表示します。Diffuserとの接続は自動的に修正しません。外径cutは翼TEを切る機能で、流路の下流壁全体を径で切り落とす機能ではありません。

派生形状のTurboGrid Profile Points／CAD／Mechanical STEPは、派生壁面と所属・ディスクの形式対応が未実装のため、書込みやジョブ用ディレクトリ作成前に拒否します。元形状を代わりに出力しません。従来の非カット出力・静翼CSVを維持します。派生設定付きJSONはschema 0.4、未指定時は以前の省略規則を維持します。

非有限値、範囲外、拡径、LE／Splitterを消す切断、交点なし／逆行、幅不足、自己交差、端部不連続をエラーにします。元基準断面が両壁に交わらない流路も拒否します。無効入力では画面に最終有効形状を表示していると明示し、Passageの計算元を消去します。

## 実装・試験の経路

- 元設計パラメータと派生設定の分離、翼列別保持、Undo／Redo／New／JSON。未指定キーは省略し既存JSONを保持する。
- 純数値モジュールでの面積断面、元翼面との交点、切断・端部接続・有効形状検証。Qtや外部形式には依存させない。
- 中央2D／3D、子午面、全周、流路面積／スロートで同じ派生形状を使用。角度／厚さ編集は元設計座標を維持し、カット位置を別に表示する。
- 派生Shroudは一般に単一Line／Arcでは表せない。元の編集可能なLine／Arcを置換せず、派生輪郭として管理する。元の所属翼列との座標対応を維持する。
- TurboGrid／CAD／壁面所属は既存の解析Line／Arcや区間長を参照するため、派生輪郭の扱いを追加確認する。対応できない経路で元設計を代わりに出力せず、書込み前に拒否して既存出力を保護する。
- 他翼列の設計を勝手に縮めない。Impeller出口とDiffuser入口等の接続は別途確認する。

## 必要な試験

1. 軸流環状面積・純径流幅の解析解、曲線壁の断面面積と指定カット率。
2. 0%／無効時の元形状・既存出力のバイト一致。元パラメータ・全制御点の不変。
3. 円筒切断の全Span外径一致、元翼面上の残存点、元座標の保持。β・厚さを0〜1へ引き伸ばしていないこと。
4. Shroud／外径の単独・併用、TE Rake、主翼／専用・連動Splitter、クリアランス、CW／CCW。
5. LEまで届くカット・逆行・自己交差・幅不足・非有限値等の拒否、古い有効形状の誤出力防止。
6. 翼列切替・Undo／Redo・保存／読込・New・表示・解析の一致、全回帰。

実ディスプレイ／F5／ANSYS Import／Mesh／CFD／実機加工・性能は自動試験と区別します。stage・commit・pushはこの作業では行いません。
