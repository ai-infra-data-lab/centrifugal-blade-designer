# 子午面区間の座標表示

左の`子午面 / Meridional`を選び、右側で`Hub`または`Shroud`を選択します。区間一覧の円弧（Arc）の行番号または入力欄をクリックすると、追加・削除ボタンの下に、その区間の**始点・中心・終点のR/Z座標[mm]**を表示します。タイトルに壁面名、区間番号、種類を表示します。直線（Line）では始点・終点を表示し、中心は「—」です。

座標は読み取り専用です。12有効桁で表示し、数値セルのツールチップには17有効桁を表示します。表示の丸めを設計値へ戻しません。Rは回転軸からの半径、Zは軸方向座標で、円弧の中心Rは構成円の中心座標です。翼列のLE／TE位置とは別の情報です。

既存の解析的な`LineSegmentGeometry.start/end`、`ArcSegmentGeometry.center`を読み取ります。プレビューのサンプル点から中心・端点を推定したり、円弧生成式をGUI内へ複製したりしません。数値計算・形状・既定値・保存形式・出力形式を変更しません。

区間の行選択やHub／Shroud切替では、表示更新だけを行い、形状再生成信号やUndo操作を追加しません。既に生成済みの有効な壁面結果を参照し、曲線定義と一致しないキャッシュや無効壁面では数値を「—」にして、古い座標を現在値として表示しません。選択前も「—」です。開始Z/R/角度、上流区間、半径・Sweep・方向、種類、追加・削除・順序変更、Undo／Redo、JSON読込による変更へ追従します。入力途中は従来どおりEnter／フォーカス移動まで確定しません。
