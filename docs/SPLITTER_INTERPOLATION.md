# 専用スプリッターの点間補間

主翼とスプリッターは同じ`geometry/distributions.py`のPCHIPを使います。従来の専用スプリッターは非表示の上流点も参照していたため、見えている点が2点でも直線にならず、主翼の編集と違って見える状態でした。

専用分布は、現在表示中のLE〜TEの点だけで補間します。角度・厚さとも2点なら直線、3点以上なら主翼と同じPCHIPです。横軸は主翼LE=0・TE=1を保ち、生成時だけLE〜TEを計算用の0〜1へ対応付けます。グラフは実際の生成分布を表示します。

LEに制御点がなければ、保存済みの元分布からLE値の初期値を取得します。その値と下流点だけを使い、非表示の上流点は区間内の傾きを決めません。いずれかの可視点を編集したとき、表示中のLEも実制御点として保存し、下流の編集でLE値が変わらないようにします。追加／削除でも同じです。

## 既存データへの影響

この変更は、コピー直後と既存JSONの専用スプリッターにも適用します。元の制御点を保持していても、補間の参照範囲が変わるため、専用スプリッターの形状が変わる場合があります。主翼連動の分布切出し、主翼、静翼、既定JSON、JSONキーや読込精度は維持します。元ファイルを自動保存・書換えしません。

横軸・Span配置・開始位置・ピッチ・厚さ倍率・TE位置／Rake・端部・クリアランスの既存の処理を使います。開始位置を変更してLEに実制御点がない場合は、新しいLE値を保存済み元分布から初期化します。範囲外の保存点は、開始位置を上流へ変更したときに再表示できます。
